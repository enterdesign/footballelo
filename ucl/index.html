ELO Formula

R = R + K × (S − E)

E = 1 / (1 + 10^((R_opp − R_self) / 400))

S: 1 = win  ·  0.5 = draw  ·  0 = loss

Base ELO = 1600 (all clubs start equal)

K-Factors

  • Group / League phase → K = 8
  • Round of 16 / Quarter-finals → K = 16
  • Semi-finals → K = 24
  • Final → K = 32
  • Qualifying rounds → K = 0 (excluded)

Notes

  • Penalty shootouts counted as draws
  • 90-minute score used throughout
  • Only group stage onwards counted

Coverage

  • 1992/93 — 2025/26 (ongoing)
  • 160 clubs · 34 seasons
  • Country codes: UEFA standard (ENG/SCO separate)
