How to get the token (once)

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → enterdesign/footballelo.
  3. Permissions → Repository permissions → Actions: Read and write (Metadata: read is added automatically).
  4. Pick an expiry (e.g. 90 days), generate, paste the token above.

The token is never part of this site: it is typed here, kept only in this browser (if you tick the box) and sent only to api.github.com. Without it nobody can start the update, even though this page is public. If you prefer, use the button on GitHub instead: Actions → Update & deploy → Run workflow.
